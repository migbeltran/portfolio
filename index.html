FlowStudio

A desktop app that turns finalized equipment selections into client-ready proposals in minutes.

FlowStudio's desktop interface — Proposal Generator
PROBLEM
After an equipment selection is finalized, estimators and sales engineers still have to manually rebuild that data into a formatted proposal. Headers, copying bill-of-materials tables from templates, and cross-checking exclusions were rewritten by hand with room for error at every step.

NYRR Volunteer Slot Tracker

A monitoring and notification system built to catch volunteer slots the moment they open.

Push notification the moment a slot opens
PROBLEM
Qualifying for guaranteed NYC Marathon entry through New York Road Runners' 9+1 volunteer program meant grabbing slots that open and fill within minutes, across multiple events at once. Manually checking 70+ roles every hour, all day, was not realistic.
APPROACH
Built an automated monitoring system that scrapes NYRR's event pages and detects slot availability, then pushes notifications through ntfy.sh's API. Since GitHub's own scheduler wasn't reliable enough for checks this time-sensitive, an external service triggers the check on schedule via GitHub's REST API. The results are also fed into a dashboard that can be accessed at any time for a live status check across all tracked events.
IMPACT
  • Built a single-page dashboard to check availability across 70+ roles at a glance, instead of manually checking each one
  • Got real-time push notifications the moment a slot opened, closing the gap between availability and action
  • Successfully secured a volunteer slot, and got a second person onto the same shift
BUILT WITH — Python · GitHub REST API · ntfy.sh notification API · scheduled automation
